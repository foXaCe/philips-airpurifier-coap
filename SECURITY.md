# Security Policy

## Supported versions

Only the latest release on the `main` branch is supported. Please update to the
newest version before reporting an issue.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[open a private security advisory](https://github.com/foXaCe/philips-airpurifier-coap/security/advisories/new).

Include as much detail as possible (affected version, reproduction steps and
impact). Target response time is 7 days.

This integration talks to Philips devices over the local network using the
encrypted CoAP protocol; it does not send data to any external cloud service.
